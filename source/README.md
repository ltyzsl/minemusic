# minemusic

桌面悬浮音乐控制气泡 — 支持 QQ 音乐，真实音频频谱可视化。

## 功能

- 🫧 **悬浮气泡** — 毛玻璃圆形气泡，悬停放大，可拖拽
- 🎵 **QQ 音乐控制** — 播放/暂停/上下首/进度拖动
- 📊 **真实频谱** — WASAPI 音频环回 + FFT，柱子随音乐真实跳动
- 🔄 **双向绑定** — QQ 音乐播放状态 ↔ 气泡视觉状态自动同步
- 🎨 **5 种频谱样式** — 柱状图 / 心电波 / 辐射圆环 / 粒子喷射 / 水波纹
- 🔊 **滚轮音量** — 气泡/跳动条/面板上滚轮调节系统音量
- 📋 **歌曲信息** — 歌名/歌手/歌词实时显示
- 📌 **系统托盘 + 任务栏** — 右键菜单显示/隐藏/退出

## 运行

### 开发模式
```bash
pip install -r requirements.txt
python main.py
```

### 打包版
下载 [Releases](../../releases) 中的 `minemusic.exe`，双击运行，无需安装任何依赖。

## 配置

首次运行自动生成 `config.json`，可编辑气泡大小、透明度、频谱样式等。

## 技术栈

- PyQt5 — GUI
- UIAutomation — 读取 QQ 音乐歌曲信息
- soundcard + numpy — WASAPI 环回 + FFT 频谱分析
- PyInstaller — 打包为单文件 exe
